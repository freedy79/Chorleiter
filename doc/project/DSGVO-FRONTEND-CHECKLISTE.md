# DSGVO Frontend Checkliste (EU/DE)

Stand: 2026-06-17

## Datenminimierung

- [ ] Formulare erfassen nur notwendige personenbezogene Daten
- [ ] Keine unnötigen PII-Felder im Frontend gespeichert

## Transparenz & Rechte

- [ ] Datenschutzerklärung leicht auffindbar (Desktop + Mobile)
- [ ] Einwilligungspunkte klar und verständlich
- [ ] Hinweise zu Betroffenenrechten auffindbar

## Client-Speicher

- [ ] LocalStorage enthält keine unnötigen personenbezogenen Klartexte
- [ ] SessionStorage auf Mindestumfang begrenzt
- [ ] Caches enthalten keine sensitiven Restdaten nach Logout

## Sicherheit

- [ ] Sensible Daten werden nicht in Fehlermeldungen offengelegt
- [ ] Demo-/Rollenbeschränkungen verhindern Bearbeitungsaktionen konsistent

## Nachweis

- [ ] Prüfschritte mit Datum, Prüfer und Ergebnis dokumentiert
