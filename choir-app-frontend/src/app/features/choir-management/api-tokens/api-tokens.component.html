Einrichtung im MCP-Client

Variante A: automatisch per OAuth (z. B. ChatGPT)

Clients, die MCP-OAuth beherrschen, brauchen keinen Token von dieser Seite. Trage dort einfach https://nak-chorleiter.de/api/mcp als Server-URL ein. Der Client registriert sich selbst, du wirst hierher zur Anmeldung geschickt, wählst den Chor und bestätigst den Zugriff. Der entstehende Token taucht anschließend oben in der Liste auf und lässt sich dort genauso widerrufen.

Variante B: Token manuell eintragen

  1. Token oben erstellen und den angezeigten Wert kopieren.
  2. Im Client einen MCP-Server vom Typ Streamable HTTP anlegen.
  3. Als URL https://nak-chorleiter.de/api/mcp eintragen und den Header Authorization: Bearer <Token> setzen.
  4. Prüfen lässt sich die Verbindung mit GET https://nak-chorleiter.de/api/mcp/info.

Ausgeliefert werden ausschließlich Chordaten. Mitglieder erscheinen nur mit ihrem Anzeigenamen, etwa als musikalische Leitung im Dienstplan. E-Mail-Adressen, Telefonnummern, Anschriften, Verfügbarkeiten, Chat- und Umfragedaten sind vollständig ausgeschlossen.
